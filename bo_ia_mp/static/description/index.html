El punto de memoria que conecta Odoo con asistentes y chats de IA. Centraliza esquema, muestras y consultas para que tu equipo pregunte en lenguaje natural y obtenga respuestas útiles para la toma de decisiones.

Deja de explicar tablas y campos en cada conversación. Memory Point indexa aplicaciones, modelos y datos de muestra, y ejecuta consultas SELECT con historial por período — ideal para dashboards conversacionales, copilotos y análisis operativo.

Diseñado para equipos que deciden con datos

Traduce la complejidad de Odoo en contexto listo para IA y para personas de negocio.

Dirección y finanzas

Ventas, facturación, inventario y nómina consultables sin depender del SQL manual.

Operaciones y RR. HH.

Respuestas rápidas sobre procesos, contratos, novedades y métricas del día a día.

TI e integradores

API REST, tokens y auditoría para enlazar ChatGPT, copilotos internos o pipelines RAG.

Qué puede hacer por ti

Capacidades reales del módulo, pensadas para escalar la inteligencia sobre tus datos Odoo.

Consultas desde chats conectados

Integra asistentes externos: generan SQL en lenguaje natural, Memory Point valida (solo SELECT) y devuelve resultados JSON para el chat.

Información centralizada

Catálogo de aplicaciones, modelos, tablas, campos y muestras en un único punto — contexto persistente para IA y equipos.

Decisiones de negocio

Consultas guardadas con ventanas de tiempo (hora, día, semana, mes) y resultados históricos para comparar tendencias y tomar decisiones.

Esquema listo para RAG

Metadatos estructurados y datos de muestra configurables — menos alucinaciones, más precisión en embeddings y asistentes.

Automatización programada

Cron horario ejecuta consultas guardadas; acumula ejecuciones por período sin intervención manual.

Seguridad y trazabilidad

API con doble factor, permisos Data IA (User / Manager), registro de llamadas y validación SELECT-only.

Dentro de Odoo

Aplicaciones y modelos
  • Vistas lista, formulario y kanban por módulo instalado
  • Pestaña Models: nombre técnico, tabla PostgreSQL y campos
  • Load Models y carga de muestras al instalar
  • JSON de muestra configurable por parámetro de sistema
API e integración
  • Guardar y listar consultas (/api/bo_ia_mp/saved_query)
  • Ejecutar SELECT ad hoc (/api/bo_ia_mp/query/execute)
  • Configurar clave de integración (/api/bo_ia_mp/token)
  • Placeholders de fecha: {{date_from}}, {{datetime_to}}, etc.
Permisos Data IA

User — consulta catálogo, consultas guardadas e historial (lectura).

Manager — administración completa, API y configuración de tokens.

Instalación
  1. Copiar bo_ia_mp al path de addons (requiere bo_license_client)
  2. Actualizar lista de aplicaciones e instalar
  3. Al instalar: carga automática de modelos y muestras
